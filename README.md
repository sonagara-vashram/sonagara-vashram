### Open Source

**[hookrecon](https://github.com/sonagara-vashram/hookrecon)**
Read-only CLI that finds Stripe payments that never reached your database. Reconciles Stripe events against Postgres and reports every missing record with its amount and a dashboard link. Python · Stripe · PostgreSQL

**[google-maps-scraper](https://github.com/sonagara-vashram/google-maps-scraper)**
Python tool that extracts business data from Google Maps into CSV using pure HTTP requests, with no browser or API key. Includes grid mode for full city coverage, proxy rotation and resumable runs. Python
